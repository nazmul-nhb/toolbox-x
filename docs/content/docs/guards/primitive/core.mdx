Collection of type-guards for runtime type checking of core primitive values, enabling TypeScript type narrowing.

## Imports

```ts
import { isNumber, isString, isBoolean, isSymbol, isBigint } from 'toolbox-x/guards';
```

---

## isNumber

Validates whether a value is a **finite number** and not `NaN`.

This function returns `true` only if:

- the value is of type `number` (not a string, object, etc.), and
- the value is **not** `NaN`, `Infinity`, or `-Infinity`.

This ensures strict numeric validation suitable for mathematical operations, user input sanitization, or database-safe values.

### Signature

```typescript
isNumber(value: unknown): value is number
```

### Examples

```typescript pg
import { isNumber } from 'toolbox-x/guards';

console.log(isNumber(42));           // true
console.log(isNumber(-5.5));         // true
console.log(isNumber('42'));         // false - string, not number
console.log(isNumber(NaN));          // false - explicitly excluded
console.log(isNumber(Infinity));     // false - not finite
console.log(isNumber(-Infinity));    // false - not finite
console.log(isNumber(null));         // false - not a number
console.log(isNumber(undefined));    // false - not a number
```

**Type Narrowing Example:**

```typescript
const input: unknown = 10;

if (isNumber(input)) {
  input.toFixed(2);     // ✅ OK - input is treated as number
} else {
  // input is still unknown here
}
```

<Callout type="idea" title="Info">
Please, refer to numeric string guard: [isNumericString](./numeric#isnumericstring) for stringified number checking.
</Callout>

## isString

Validates if a value is a string.

### Signature

```typescript
isString(value: unknown): value is string
```

### Examples

```typescript pg
import { isString } from 'toolbox-x/guards';

console.log(isString('hello'));      // true
console.log(isString(123));          // false
console.log(isString(null));         // false

// Practical usage
function capitalize(input: unknown): string {
  if (!isString(input)) {
    throw new Error('Input must be a string');
  }
  return input.charAt(0).toUpperCase() + input.slice(1);
}

console.log(capitalize('hello'));
```

## isSymbol

Validates if a value is a Symbol.

### Signature

```typescript
isSymbol(value: unknown): value is symbol
```

### Examples

```typescript pg
import { isSymbol, isObject } from 'toolbox-x/guards'; 

const sym = Symbol('key');

console.log(isSymbol(sym));          // true
console.log(isSymbol('symbol'));     // false
console.log(isSymbol(42));           // false

// Practical usage with symbol properties
const PRIVATE_KEY = Symbol('private');
const obj = { [PRIVATE_KEY]: 'secret' };

function getPrivateValue(instance: unknown): string {
  if (!isObject(instance) || !isSymbol(PRIVATE_KEY)) {
    throw new Error('Invalid instance');
  }
  return instance[PRIVATE_KEY];
}

console.log(getPrivateValue(obj));
```

### Key Notes

1. Returns true only for actual Symbol primitives
2. Useful for working with unique identifier patterns
3. Helps maintain type safety when using Symbol properties

## isBigInt

Checks if a value is a BigInt primitive. Essential for working with large integers.

### Signature

```typescript
isBigInt(value: unknown): value is bigint
```

### Examples

```typescript pg
import { isBigInt } from 'toolbox-x/guards';

// BigInt detection
console.log(isBigInt(1n));                  // true
console.log(isBigInt(BigInt(42)));          // true

// Non-BigInt
console.log(isBigInt(42));                  // false
console.log(isBigInt('42'));                // false

// Type-safe operations
const largeNumber: unknown = 9007199254740993n;
if (isBigInt(largeNumber)) {
  const squared = largeNumber * largeNumber; // valid operation
  console.log(squared)
}

// Edge cases
console.log(isBigInt(null));                // false
console.log(isBigInt(undefined));           // false
```

### Use Cases

- Safe operations on large integers
