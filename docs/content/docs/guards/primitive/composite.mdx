Runtime type guards to validate composite primitive values.

## Imports

```typescript
import { isPrimitive, isNormalPrimitive, isNonEmptyString, isFalsy, isTruthy } from 'toolbox-x/guards';
```

---

## isPrimitive

Validates if a value is a JavaScript primitive. It covers `string | number | boolean | symbol | bigint | null | undefined`

### Signature

```typescript
isPrimitive(value: unknown): value is Primitive
```

### Examples

```typescript pg
import { isPrimitive } from 'toolbox-x/guards'; 

console.log(isPrimitive('hello'));       // true
console.log(isPrimitive(42));            // true
console.log(isPrimitive(null));          // true
console.log(isPrimitive({}));            // false
console.log(isPrimitive(Symbol('id')));  // true
console.log(isPrimitive(123n));          // true (Bigint)
```

## isFalsy

Validates if a value is falsy.

### Signature

```typescript
isFalsy(value: unknown): value is FalsyPrimitive
```

### Examples

```typescript pg
import { isFalsy } from 'toolbox-x/guards';

console.log(isFalsy(false));         // true
console.log(isFalsy(0));             // true
console.log(isFalsy(''));            // true
console.log(isFalsy('hello'));       // false
```

---

## isTruthy

Validates if a value is truthy.

### Signature

```typescript
isTruthy<T>(value: T): value is Exclude<T, FalsyPrimitive>
```

### Examples

```typescript pg
import { isTruthy } from 'toolbox-x/guards';

console.log(isTruthy('hello'));      // true
console.log(isTruthy(42));           // true
console.log(isTruthy(true));         // true
console.log(isTruthy(null));         // false
```
