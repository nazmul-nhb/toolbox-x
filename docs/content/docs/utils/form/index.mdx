## Overview

A collection of utility functions for handling form data. These utilities provide type-safe ways to convert objects into `FormData` payloads (including nested fields and files), serialize HTML form inputs into structured objects, and parse `FormData` objects back into JavaScript types.

## Categories

### [Create Form Data](./form/create-form-data)

Converts objects, arrays, and nested structures into standard, web-compatible `FormData` instances.

### [Parse Form Data](./form/parse-form-data)

Converts a `FormData` object back into a standard JavaScript object, reconstructing nested paths and array fields.

### [Serialize Form](./form/serialize-form)

Serializes raw HTML Form elements directly into key-value JavaScript objects.
