## Overview

A collection of general-purpose utilities. These include tools for action debouncing/throttling, safe JSON stringifying/parsing, prototype extension, country phone lookup, class method inspection, HTTP status helpers, and console log styling.

## Categories

### Action Utilities

- [debounceAction](./misc/debounce-action) — Delays function execution until after a specified wait time has elapsed.
- [throttleAction](./misc/throttle-action) — Limits the rate at which a function is executed.

### Data & JSON Utilities

- [convertArrayToString](./misc/convert-array-to-string) — Converts array values to readable strings with customization.
- [deepParsePrimitives](./misc/deep-parse-primitives) — Recursively parses all string values in an object to their actual types.
- [jsonStringify](./misc/json-stringify) — Stable, sorted, and circular-safe JSON stringifier.
- [parseJSON](./misc/parse-json) — Safe JSON parser that never throws and optionally parses primitives.

### Class & Prototype Utilities

- [classMethods](./misc/class-methods) — Introspects class names, instance methods, and static methods.
- [definePrototypeMethod](./misc/define-prototype-method) — Safe utility to extend JavaScript prototypes.

### Specialized Singletons

- [getCountryByPhone](./misc/get-country-by-phone) — Identifies country and formats phone numbers by dial code.
- [httpStatus](./misc/http-status) — A singleton instance of `HttpStatus` providing status code checks and text lookup.
- [stylog](./misc/stylog) — A singleton instance of `LogStyler` to format console logs with styles.
- [stylogUtils](./misc/stylog-utils) — Supporting utilities for console logging.
