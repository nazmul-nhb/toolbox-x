After installation you can import any utility or class from `toolbox-x` or from the specific sub modules.

## Examples

### 🎨 Professional Color Manipulation

**`Color`** - Convert between color formats, generate palettes, check accessibility contrast, and perform advanced color math with perfect type safety.

```typescript pg
import { Color } from 'toolbox-x/colors';

const blue = new Color('#0000ff');
const darkerBlue = blue.applyDarkness(20); // 20% darker
console.log(darkerBlue.hsl); // "hsl(240, 100%, 30%)" (was 50%)
```

[Documentation →](/docs/classes/Color)

### 🔍 Optimized Array Search

**`Finder`** - Blazing-fast array searching with binary search, fuzzy matching, and smart caching. Perfect for large datasets.

```typescript pg
import { Finder } from 'toolbox-x';

const products = [
 { name: 'Laptop', category: 'Electronics', price: 1200 },
 { name: 'Mouse', category: 'Accessories', price: 25 },
 { name: 'Keyboard', category: 'Accessories', price: 75 },
 { name: 'Monitor', category: 'Electronics', price: 300 },
];

const productFinder = new Finder(products);

const laptop = productFinder.findOne('laptop', 'name', {
 fuzzy: true,
 caseInsensitive: true,
});

console.log(laptop);
```

### 🔢 Pluralize Strings and More

**`pluralizer`** - Handles English word pluralization and singularization with support for irregular forms and uncountable nouns.

```typescript pg
import { pluralizer } from 'toolbox-x/pluralizer';

const result1 = pluralizer.pluralize('child'); // "children"
const result2 = pluralizer.pluralize('category', { count: 3 }); // "categories"
const result3 = pluralizer.pluralize('child', { count: 1, inclusive: true }); // "1 child"

const result4 = pluralizer.toSingular('geese'); // "goose"
const result5 = pluralizer.toSingular('children'); // "child"

const result6 = pluralizer.isPlural('children'); // true
const result7 = pluralizer.isSingular('child'); // true
const result8 = pluralizer.isPlural('fish'); // true (uncountable)

console.log({
    result1,
    result2,
    result3,
    result4,
    result5,
    result6,
    result7,
    result8,
});
```

### 📄 FormData Preparation

**`createFormData`** - Convert JavaScript objects into `FormData` with extensive configuration options for handling nested structures, files, and data transformations.

```typescript pg
import { createFormData } from 'toolbox-x/dom';

const file1 = new File(['file1'], 'file1.txt', { type: 'text/plain' });
const file2 = new File(['file2'], 'file2.txt', { type: 'text/plain' }); 

const data = {
  user: {
    name: ' John Doe ',
    age: 30,
    preferences: { theme: 'dark' }
  },
  files: [file1, file2]
};

const formData = createFormData(data, {
  trimStrings: true,
  lowerCaseValues: ['user.name'],
  dotNotateNested: ['user'],
  breakArray: ['files']
});

console.log(Object.fromEntries(formData));

// Resulting FormData:
// user.name=john doe
// user.age=30
// user.preferences.theme=dark
// files[0]=[File1]
// files[1]=[File2]
```

[Documentation →](/docs/utilities/form/create-form-data)

### 🛡️ Data Sanitization

**`sanitizeData`** - Clean and normalize strings/objects by trimming whitespace, removing empty values, and applying customizable filters.

```typescript pg
import { sanitizeData } from 'toolbox-x';

const user = {
 name: '  John Doe  ',
 age: null,
 address: { city: '  NYC  ', zip: '' },
 tags: [],
};

const sanitized1 = sanitizeData(user, { ignoreFalsy: true, ignoreEmpty: true });
// Returns { name: "John Doe", address: { city: "NYC" } } with exact input type which may cause issue when accessing missing properties
console.log(sanitized1);

const sanitized2 = sanitizeData(user, { ignoreFalsy: true, ignoreEmpty: true }, 'partial');
// Return type: $DeepPartial<typeof user> safe property access by making all the properties (nested objects/arrays) optional 
// Returns { name: "John Doe", address: { city: "NYC" } }
console.log(sanitized2);
```

### 🔢 Advanced Number Operations

**`getNumbersInRange`** - Generate intelligent number sequences with prime, even/odd, and custom filtering capabilities

```typescript pg
import { getNumbersInRange } from 'toolbox-x';

// Get primes between 10-30 as formatted string
const primesString = getNumbersInRange('prime', { min: 10, max: 30, getAsString: true });
// "11, 13, 17, 19, 23, 29"
console.log(primesString);

// Get even numbers between 1-10 as array
const evensArray = getNumbersInRange('even', { min: 1, max: 10 });
// [2, 4, 6, 8, 10]
console.log(evensArray);
```

[Documentation →](/docs/utilities/number/get-numbers-in-range)

### 🔄 Extract Updated Fields

**`extractUpdatedFields`** - Detect exactly what changed between two objects (including deep nested changes).

```typescript pg
import { extractUpdatedFields } from 'toolbox-x';

const dbRecord = { id: 1, content: 'Hello', meta: { views: 0 } };
const update = { content: 'Hello', meta: { views: 1 } };
const result = extractUpdatedFields(dbRecord, update);
// { meta: { views: 1 } }
console.log(result);
```
