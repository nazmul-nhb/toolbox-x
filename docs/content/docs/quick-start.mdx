## Creating Instances

There are multiple ways to create a `Chronos` instance:

### Using the Constructor

```ts
import { Chronos } from "toolbox-x";

// Current date and time
const now = new Chronos();

// From a date string
const date = new Chronos("2025-12-31");

// From a timestamp
const fromTimestamp = new Chronos(1735689600000);

// From a Date object
const fromDate = new Chronos(new Date());

// From components
const custom = new Chronos(2025, 6, 15, 14, 30, 0);
```

## Basic Operations

```ts pg
import { Chronos } from "toolbox-x";

const date = new Chronos("2025-06-15");

// Formatting
console.log({
    format: date.format("mmmm DD, YYYY"),
    format2: date.format("ddd")
});

// Arithmetic
console.log({
    add7days: date.add(7, "day").format(),
    subtract1month: date.subtract(1, "month").format()
});

// Comparison
const other = new Chronos("2025-07-01");
console.log({
    isBeforeJuly: date.isBefore(other, "month"),
    daysBetween: date.diff(other, "day")
});
```

## Using Plugins

Extend Chronos with plugins for additional functionality:

```ts pg
import { Chronos } from "toolbox-x";
import { timeZonePlugin } from "toolbox-x/plugins/timeZonePlugin";
import { seasonPlugin } from "toolbox-x/plugins/seasonPlugin";

// Register plugins (do this once, before creating instances)
Chronos.use(timeZonePlugin);
Chronos.use(seasonPlugin);

const date = new Chronos();
console.log({
    original: date,
    // Now you can use plugin methods
    timeZone: date.timeZone("America/New_York"), // Convert to timezone
    season: date.season() // Get current season
});
```

<Callout type="info" title="Important">
Register plugins at the top of your application entry point, before creating any `Chronos` instances.
</Callout>
