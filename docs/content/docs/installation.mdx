## Choose a Package Manager

Install `toolbox-x` using your preferred package manager:

```package-install
toolbox-x
```

## Module Formats

`toolbox-x` ships as both ESM and CommonJS:

```ts
// ESM (recommended)
import { sanitizeData } from "toolbox-x";

// CommonJS
const { sanitizeData } = require("toolbox-x");
```

## Modular Imports

You can import specific sub-modules for better tree-shaking:

```ts
// Guards
import { isString, isNumber } from "toolbox-x/guards";

// Specific functions
import { formatDate } from "toolbox-x/date";

// General type definitions
import type { Maybe } from "toolbox-x/types";

// Specific type definitions
import type { SomeType } from "toolbox-x/types/module";

// Constants
import { MONTHS } from "toolbox-x/constants";
```
