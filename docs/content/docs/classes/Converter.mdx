## `Converter` & Unit Conversion Classes

The **Unit Converter** system provides a comprehensive solution for converting values between different measurement units across multiple categories including **time**, **length**, **data**, **temperature**, **mass**, **area**, and **volume**.

The system consists of a main `Converter` function (or its alias `converter`) and specialized converter classes that automatically handle unit detection and provide type-safe conversion methods.

### Import

```typescript
import { 
  Converter, 
  converter, // Alias for Converter
  TimeConverter,
  LengthConverter, 
  DataConverter,
  TemperatureConverter,
  MassConverter,
  AreaConverter,
  VolumeConverter
} from 'toolbox-x/converter';
```

---

### Example Usage

```ts pg tab="Automatic Detection"
import { Converter, converter } from 'toolbox-x/converter';

// Time category auto-detected
const time = Converter(90, 'minute');
console.log(time.to('hour')); // → 1.5

// Length category auto-detected
const length = Converter(5, 'kilometer');
console.log(length.to('mile')); // → 3.10686

// Temperature category auto-detected
const temp = Converter(25, 'celsius');
console.log(temp.to('fahrenheit')); // → 77
```

```ts pg tab="Mathematical Operations"
import { Converter } from 'toolbox-x/converter';

const time = Converter(1, 'hour');

// Add, subtract, multiply, divide chains
console.log(time.add(30).toString());     // → "31 hours"
console.log(time.subtract(15).toString()); // → "14 hours"
console.log(time.multiply(2).toString());  // → "2 hours"
console.log(time.divide(4).toString());    // → "0.25 hours"
```

```ts pg tab="Formatting"
import { Converter } from 'toolbox-x/converter';

const length = Converter(5.25, 'kilometer');

console.log(length.formatTo('mile')); // → "3.26 miles" (plural style)
console.log(length.formatTo('mile', { style: 'compact' })); // → "3.26mi"
console.log(length.formatTo('mile', { style: 'scientific', decimals: 4 })); // → "3.2622e+0 mile"
```

## Common Methods (All Converters)

All converter instances inherit these methods from the base class:

### `to(targetUnit)`
Converts to a specific target unit.
```typescript
Converter(60, 'minute').to('hour'); // 1
```

### `toAll()`
Converts the current value to all available units in the category.
```typescript
Converter(90, 'minute').toAll();
// { second: 5400, minute: 90, hour: 1.5, ... }
```

### `formatTo(targetUnit, options?)`
Formats the converted value with various styling options (`'compact' | 'scientific' | 'plural'`) and custom decimals.

### `getValue()` / `valueOf()`
Returns the raw numeric value.

### `getUnit()`
Returns the current unit name.

### `toString()`
Returns a formatted string with automatic pluralization (e.g. `"2.5 hours"`).

### `toObject()`
Returns an object representation: `{ value: 2.5, unit: "hour" }`.

## Category-Specific Details

### `TimeConverter`
- **Units**: `nanosecond`, `microsecond`, `millisecond`, `second`, `minute`, `hour`, `day`, `week`, `month`, `year`, `decade`, `century`, `millennium`
- **Base Unit**: `second`

### `LengthConverter`
- **Units**: `millimeter`, `centimeter`, `meter`, `kilometer`, `inch`, `foot`, `yard`, `mile`, `nautical-mile`, `light-year`
- **Base Unit**: `meter`

### `DataConverter`
- **Units**: `bit`, `byte`, `kilobit`, `kilobyte`, `megabit`, `megabyte`, `gigabit`, `gigabyte`, `terabit`, `terabyte`, `petabit`, `petabyte`
- **Base Unit**: `byte`

### `TemperatureConverter`
- **Units**: `celsius`, `fahrenheit`, `kelvin`
- **Formula**: Uses specific conversion formulas (non-linear).

### `MassConverter`
- **Units**: `microgram`, `milligram`, `gram`, `kilogram`, `tonne`, `ounce`, `pound`, `stone`, `short-ton`, `long-ton`
- **Base Unit**: `kilogram`

### `AreaConverter`
- **Units**: `square-millimeter`, `square-centimeter`, `square-meter`, `square-kilometer`, `square-inch`, `square-foot`, `square-yard`, `square-mile`, `hectare`, `acre`
- **Base Unit**: `square-meter`

### `VolumeConverter`
- **Units**: `cubic-millimeter`, `cubic-centimeter`, `cubic-meter`, `cubic-kilometer`, `cubic-inch`, `cubic-foot`, `cubic-yard`, `liter`, `milliliter`, `gallon`, `quart`, `pint`, `cup`, `tablespoon`, `teaspoon`
- **Base Unit**: `cubic-meter`
