---
title: Area Conversions
description: Static methods for converting between area units — square meters, square feet, square kilometers, and square inches.
---

## sqmToSqft()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.sqmToSqft(1)); // → 10.7639
```

---

## sqftToSqm()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.sqftToSqm(10.7639)); // → 1
```
