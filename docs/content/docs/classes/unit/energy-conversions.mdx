---
title: Energy Conversions
description: Static methods for converting between energy units — joules, calories, and kilojoules.
---

## joulesToCalories()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.joulesToCalories(4.184)); // → 1
```

---

## caloriesToJoules()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.caloriesToJoules(1)); // → 4.184
```

---

## caloriesToKJoules()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.caloriesToKJoules(1000)); // → 4.184
```

---

## kJoulesToCalories()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.kJoulesToCalories(4.184)); // → 1000
```
