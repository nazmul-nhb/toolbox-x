---
title: Volume Conversions
description: Static methods for converting between volume units — milliliters, liters, and gallons.
---

## mlToLiters()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.mlToLiters(1000)); // → 1
```

---

## litersToMl()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.litersToMl(1)); // → 1000
```

---

## gallonsToMl()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.gallonsToMl(1)); // → 3785.41
```

---

## mlToGallons()

```ts pg
import { Unit } from 'toolbox-x';
```

## litersToGallons()

```ts pg
import { Unit } from 'toolbox-x';
```

