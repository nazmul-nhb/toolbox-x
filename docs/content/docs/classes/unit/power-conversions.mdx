---
title: Power Conversions
description: Static methods for converting between power units — watts and kilowatts.
---

## wattsToKw()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.wattsToKw(1000)); // → 1
```

---

## kwToWatts()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.kwToWatts(1)); // → 1000
```
