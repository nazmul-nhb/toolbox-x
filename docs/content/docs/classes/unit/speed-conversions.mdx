---
title: Speed Conversions
description: Static methods for converting between speed units — km/h and mph.
---

## kmphToMph()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.kmphToMph(100)); // → 62.1371
```

---

## mphToKmph()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.mphToKmph(62.1371)); // → 100
```
