---
title: Frequency Conversions
description: Static methods for converting between frequency units — hertz, kilohertz, and megahertz.
---

## hzToKHz()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.hzToKHz(1000)); // → 1
```

---

## kHzToHz()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.kHzToHz(1)); // → 1000
```

---

## hzToMHz()

```ts pg
import { Unit } from 'toolbox-x';

```
