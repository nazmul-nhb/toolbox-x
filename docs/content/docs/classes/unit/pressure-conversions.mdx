---
title: Pressure Conversions
description: Static methods for converting between pressure units — atmospheres, pascals, and bar.
---

## atmToPascal()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.atmToPascal(1)); // → 101325
```

---

## pascalToAtm()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.pascalToAtm(101325)); // → 1
```

---

## barToPascal()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.barToPascal(1)); // → 100000
```

---

## pascalToBar()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.pascalToBar(100000)); // → 1
```
