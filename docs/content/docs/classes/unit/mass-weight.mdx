---
title: Mass & Weight Conversions
description: Static methods for converting between mass and weight units — kilograms, pounds, grams, and ounces.
---

## kgToLbs()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.kgToLbs(1)); // → 2.20462
```

---

## lbsToKg()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.lbsToKg(2.20462)); // → 1
```

---

## gramsToOunces()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.gramsToOunces(28.3495)); // → 1
```

---

## ouncesToGrams()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.ouncesToGrams(1)); // → 28.3495
```
