---
title: Length Conversions
description: Static methods for converting between length units — meters, feet, kilometers, miles, centimeters, and millimeters.
---

## metersToFeet()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.metersToFeet(1)); // → 3.28084
```

---

## feetToMeters()

```ts pg
import { Unit } from 'toolbox-x';
console.log(Unit.feetToMeters(3.28084)); // → 1
```
