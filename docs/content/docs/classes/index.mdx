## Specialized Classes for Complex Problems

`toolbox-x` includes robust classes that encapsulate advanced functionalities:

- [**`Color`**](./color) — Comprehensive color management, scheme generation, manipulation, and accessibility contrast checkers.
- [**`Pluralizer`**](./pluralizer) — Noun form (`Singular` ↔ `Plural`) conversion with custom rule registers.
- [**`Verbalizer`**](./verbalizer) — Verb form (`Base` ↔ `Past` ↔ `Past Participle`) conversion.
- [**`LogStyler`**](./log-styler) — Console output styling class.
- [**`HttpStatus`**](./http-status) — Elegant HTTP status codes registry and management.
- [**`Converter`**](./converter) — Comprehensive Measurement Conversion class.
- [**`Cipher`**](../utils/hash/cipher) — Encrypt/decrypt text with stream-cipher style.
- [**`Signet`**](../utils/hash/signet) — Sign, decode, and verify tokens in JWT style.
- [**`TextCodec`**](../utils/hash/text-codec) — Convert text between hex, binary, and Base64 formats.
- [**`Finder`**](./finder) — Sophisticated cached array searching.
- [**`Paginator`**](./paginator) — Elegant pagination handling.
- [**`Unit`**](./unit) & [**`Currency`**](./currency) — Unit and currency handling.

## Key Features

- Immutable operations where applicable.
- Chainable method patterns for `Color` and `LogStyler`.
- Type-safe inputs and outputs.
