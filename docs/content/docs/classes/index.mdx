## Specialized Classes for Complex Problems

`toolbox-x` includes robust classes that encapsulate advanced functionalities:

- [**`Color`**](/docs/classes/color) — Comprehensive color management, scheme generation, manipulation, and accessibility contrast checkers.
- [**`Pluralizer`**](/docs/classes/pluralizer) — Noun form (`Singular` ↔ `Plural`) conversion with custom rule registers.
- [**`Verbalizer`**](/docs/classes/verbalizer) — Verb form (`Base` ↔ `Past` ↔ `Past Participle`) conversion.
- [**`LogStyler`**](/docs/classes/log-styler) — Console output styling class.
- [**`HttpStatus`**](/docs/classes/http-status) — Elegant HTTP status codes registry and management.
- [**`Converter`**](/docs/classes/converter) — Comprehensive Measurement Conversion class.
- [**`Cipher`**](/docs/utils/hash/Cipher) — Encrypt/decrypt text with stream-cipher style
- [**`Signet`**](/docs/utils/hash/Signet) — Sign, decode, and verify tokens in JWT style.
- [**`TextCodec`**](/docs/utils/hash/TextCodec) — Convert text between hex, binary, and Base64 formats.
- [**`Finder`**](/docs/classes/finder) — Sophisticated cached array searching.
- [**`Paginator`**](/docs/classes/paginator) — Elegant pagination handling.
- [**`Unit`**](/docs/classes/unit) & [**`Currency`**](/docs/classes/currency) — Unit and currency handling.

## Key Features

- Immutable operations where applicable.
- Chainable method patterns for `Color` and `LogStyler`.
- Type-safe inputs and outputs.
