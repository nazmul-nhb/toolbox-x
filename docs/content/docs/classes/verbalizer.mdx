title: Verbalizer
description: Low-level API for English verb conjugation between base, past tense, and past participle forms with support for irregular verbs and custom rules.
---

The **`Verbalizer`** class provides a low‑level API to handle English verb conjugation between base, past tense, and past participle forms. It supports **irregular verbs**, **regular conjugation rules**, and allows you to **extend or customize** the behavior by adding new rules.

<Callout type="info" title="When to Use">
- You need **multiple independent configurations**.
- You want to **add or override rules** without affecting the shared `verbalizer` instance.
</Callout>

## Features

- ✅ Convert verbs between **base**, **past tense**, and **past participle** forms.
- ✅ Built‑in **default rules** loaded on construction.
- ✅ Manage rules dynamically: `addBaseRule()`, `addPastRule()`, `addParticipleRule()`, `addIrregular()`.
- ✅ Automatically handles **irregular verbs** (e.g. `go → went → gone`).
- ✅ Preserves **case sensitivity** of input verbs.

<Callout type="warn" title="Alert">
All methods return the trimmed verb if the input has trailing spaces.
</Callout>

## Import

```ts
import { Verbalizer } from 'toolbox-x/verbalizer';
```

## Usage

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();

console.log(myVerbalizer.toPast('run'));         // → "ran"
console.log(myVerbalizer.toParticiple('go'));     // → "gone"
console.log(myVerbalizer.toBase('went'));         // → "go"
console.log(myVerbalizer.isPast('ran'));           // → true
```

## Extending Rules

You can modify your instance without affecting others:

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();

// Add a custom base rule
myVerbalizer.addBaseRule(/ied$/i, 'y');

// Add a custom past tense rule
myVerbalizer.addPastRule(/e$/i, 'ed');

// Add a custom past participle rule
myVerbalizer.addParticipleRule(/e$/i, 'ed');

// Add an irregular verb
myVerbalizer.addIrregular('swim', 'swam', 'swum');
```

## API Reference

### constructor()

Initializes with built‑in rules and irregular verbs.

---

### toPast(verb)

Convert a verb to its past tense form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.toPast('walk')); // → "walked"
console.log(myVerbalizer.toPast('run'));  // → "ran"
```

---

### toParticiple(verb)

Convert a verb to its past participle form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.toParticiple('walk')); // → "walked"
console.log(myVerbalizer.toParticiple('go'));    // → "gone"
```

---

### toBase(verb)

Convert a verb to its base form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.toBase('went'));   // → "go"
console.log(myVerbalizer.toBase('walked')); // → "walk"
```

---

### isPast(verb)

Check if a verb is in past tense form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.isPast('ran')); // → true
console.log(myVerbalizer.isPast('run')); // → false
```

---

### isParticiple(verb)

Check if a verb is in past participle form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.isParticiple('gone')); // → true
console.log(myVerbalizer.isParticiple('go'));    // → false
```

---

### isBase(verb)

Check if a verb is in base form.

```ts pg
import { Verbalizer } from 'toolbox-x/verbalizer';

const myVerbalizer = new Verbalizer();
console.log(myVerbalizer.isBase('run')); // → true
```
