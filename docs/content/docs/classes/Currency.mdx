## `Currency`

The `Currency` class provides utilities for handling currency operations including formatting and conversion. It supports locale-specific formatting and uses the Frankfurter API for currency conversion with automatic rate caching.

### Import

```typescript
import { Currency } from 'toolbox-x';
```

---

### Constructor

Creates a new `Currency` instance with specified amount and currency code.

#### Signature

```typescript
constructor<Code extends CurrencyCode>(amount: Numeric, code: Code): Currency<Code>
```

#### Parameters

- `amount`: Numeric value (`number` or `string`) representing the currency amount.
- `code`: ISO 4217 currency code (e.g., `'USD'`, `'EUR'`).

#### Behavior

- Converts amount to a `number` internally.
- Stores formatted currency string using `'en-US'` locale by default.

#### Example

```typescript
new Currency(100, 'USD'); // $100.00
```

---

### Example Usage

```ts pg tab="Basic Usage"
import { Currency } from 'toolbox-x';

const usd = new Currency(100, 'USD');
console.log(usd.currency); // → "$100.00"
console.log(usd.format('ja-JP', 'JPY')); // → "￥100"
```

```ts pg tab="Currency Conversion"
import { Currency } from 'toolbox-x';

const usd = new Currency(100, 'USD');
// Convert to EUR using live rates
const converted = await usd.convert('EUR', {
  fallbackRate: 0.92
});
console.log(converted.currency); // EUR equivalent, e.g. "€92.00"
```

```ts pg tab="Error Handling"
import { Currency } from 'toolbox-x';

try {
  // Convert to an unsupported currency code
  const converted = await new Currency(100, 'USD').convert('XYZ' as any);
} catch (error: any) {
  console.error('Conversion failed:', error.message);
}
```

## API Reference for Currency

### format()

Formats the currency amount according to specified locale rules.

#### Signature

```typescript
format(locale?: LocaleCode, code?: CurrencyCode): string
```

#### Parameters

- `locale`: Optional BCP 47 locale code (e.g., `'de-DE'`).
- `code`: Optional ISO 4217 currency code (e.g., `'USD'`, `'EUR'`) used solely for formatting purposes. *This does not alter the internal currency code set during instantiation.*

#### Return Value

Formatted currency string.

#### Example

```typescript
new Currency(1000, 'EUR').format('de-DE'); // "1.000,00 €"
new Currency(1000, 'EUR').format('de-DE', 'GBP'); // "1.000,00 £"
```

---

### convert()

Converts the current currency amount to a target currency using **real-time exchange rates** from [api.frankfurter.app](https://api.frankfurter.app/latest).  
Includes automatic caching, error fallback handling, and support for manually defined rates. Please refer to [convertSync](#convertsync) for a synchronous and network-independent solution.

#### Signature

```typescript
async convert<To extends FrankFurterCurrency>(to: To, options?: ConvertOptions): Promise<Currency<To>>
```

#### Parameters

- `to`: Target currency code to convert to. Must be a valid Frankfurter API supported currency (e.g., `'EUR'`, `'USD'`).
- `options` *(optional)*:
  - `fallbackRate`: A manual exchange rate to use if the API call fails or the currency is not supported.
  - `forceRefresh`: If `true`, forces a fresh fetch from the API, ignoring cached rates.

#### Return Value

A new `Currency` instance containing the converted amount in the target currency.

#### Throws

Throws an error if the API call fails **and** no `fallbackRate` is provided in options.

#### Behavior Details

- Caches conversion rates internally to avoid redundant API requests.
- Respects `forceRefresh` to bypass the cache when needed.
- Falls back to the provided `fallbackRate` if the live API fails or the currency is unsupported.
- Logs a warning in the console when falling back to a manual rate.

#### Supported Currencies (Frankfurter API)

Only the following fiat currencies are supported by the live API:

```text
AUD, BGN, BRL, CAD, CHF, CNY, CZK, DKK, EUR, GBP, HKD, HUF,
IDR, ILS, INR, ISK, JPY, KRW, MXN, MYR, NOK, NZD, PHP, PLN,
RON, SEK, SGD, THB, TRY, USD, ZAR
```

<Callout type="info" title="Alternative">
Use the `convertSync` method to convert to other currencies using a custom exchange rate.
</Callout>

#### Example

```typescript
const usd = new Currency(100, 'USD');

// Convert to EUR using live rates
const eur = await usd.convert('EUR');

// Convert with fallback if API fails
const inr = await usd.convert('INR', {
  fallbackRate: 83.12,
});
```

### convertSync()

Converts currency *synchronously* using either a cached rate or a manually provided exchange rate.
*No network requests are made.*

#### Signature

```typescript
convertSync<To extends CurrencyCode>(to: To, rate: number): Currency<To>
```

#### Parameters

- `to`: Target currency code.
- `rate`: Manual exchange rate to use if no cached rate is available.

#### Return Value

- A new `Currency` instance with the converted amount.
- If no cached rate is found, the given manual rate is used.
- If no exchange rate is valid, returns the original currency instance.

#### Example

```typescript
const eur = new Currency(100, 'USD').convertSync('EUR', 0.92);
```

---

### clearRateCache()

Clears all cached exchange rates to force fresh API calls.

#### Signature

```typescript
static clearRateCache(): void
```

#### Example

```typescript
Currency.clearRateCache();
```

## Type Definitions

### `LocaleCode`

Supported BCP 47 locale codes for formatting (e.g. `'bn-BD'`, `'en-US'`, `'zh-CN'`, `'en-GB'`).

### `CurrencyCode`

Union of all supported currency codes in your system, including ISO 4217 and custom mappings (e.g. `'BDT'`, `'USD'`, `'EUR'`, `'GBP'`).

### `FrankFurterCurrency`

Subset of `CurrencyCode` that are officially supported by the Frankfurter API:
`"USD" | "AUD" | "BGN" | "BRL" | "CAD" | "CHF" | "CNY" | "CZK" | "DKK" | "EUR" | "GBP" | "HKD" | "HUF" | "IDR" | "ILS" | "INR" | "ISK" | "JPY" | "KRW" | "MXN" | "MYR" | "NOK" | "NZD" | "PHP" | "PLN" | "RON" | "SEK" | "SGD" | "THB" | "TRY" | "ZAR"`

### `ConvertOptions`

```typescript
interface ConvertOptions {
  fallbackRate?: number;
  forceRefresh?: boolean;
}
```
