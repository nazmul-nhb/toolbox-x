## nextPage()

```typescript
nextPage(): number | null
```

Returns the next page number, or `null` if already on the last page.

```ts pg
import { Paginator } from 'toolbox-x';

console.log(new Paginator({ totalItems: 100, currentPage: 5 }).nextPage());  // → 6
console.log(new Paginator({ totalItems: 100, currentPage: 10 }).nextPage()); // → null
```

## pageList()

```typescript
pageList(options?: PageListOptions): number[]
```

Generates an array of page numbers for UI display.

### Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `options` | `PageListOptions` (optional) | Configuration for page list generation. |

```typescript
interface PageListOptions {
  edgeCount?: number; // default: 1
  siblingCount?: number; // default: 1
}
```

### Behavior

- Always shows first/last `edgeCount` pages.
- Shows `siblingCount` pages around current page.
- Merges overlapping ranges.

### Example

```ts pg
import { Paginator } from 'toolbox-x';

// For 10 total pages, current page 5:
const pages = new Paginator({ totalItems: 100, currentPage: 5 })
  .pageList({ edgeCount: 1, siblingCount: 1 });
console.log(pages); // → [1, 4, 5, 6, 10]
```
