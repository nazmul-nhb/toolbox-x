## isPageValid()

### Signature

```typescript
isPageValid(page: number): boolean
```

### Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `page` | `number` | Page number to validate. |

### Returns

- **`boolean`**: Whether the page is within the valid range.

### Example

```ts pg
import { Paginator } from 'toolbox-x/paginator';

const p = new Paginator({ totalItems: 100 });
console.log(p.isPageValid(5));  // → true
console.log(p.isPageValid(15)); // → false
```
